# Apple Wallet Pass Signing Guide

This guide explains how to sign your unsigned PKPass file so it can be installed on iOS devices.

## Prerequisites

1. **Apple Developer Account**
   - Enroll in Apple Developer Program ($99/year)
   - Visit: https://developer.apple.com/programs/

2. **Apple Certificates**
   - Pass Type ID Certificate
   - WWDR (Worldwide Developer Relations) Certificate
   - Apple Root Certificate

3. **Credentials**
   - Team ID (found in Apple Developer account)
   - Pass Type ID (format: `pass.com.example.appname`)

## Step 1: Create Pass Type ID in Apple Developer

1. Log in to https://developer.apple.com/account
2. Go to **Certificates, Identifiers & Profiles**
3. Select **Identifiers**
4. Click the **+** button to add new identifier
5. Select **Pass Type IDs**
6. Enter description (e.g., "Hidden Disabilities Sunflower Card")
7. Set ID to `pass.com.yourdomain.sunflowercard`
8. Click **Continue** and **Register**

## Step 2: Generate Pass Type ID Certificate

1. In Apple Developer, go to **Certificates**
2. Click **+** to add new certificate
3. Select **Pass Type ID Certificate**
4. Select your Pass Type ID
5. Upload a Certificate Signing Request (CSR)
   - Generate on Mac using Keychain Access
   - Or use OpenSSL (see below)
6. Download certificate (.cer file)
7. Double-click to install in Keychain (Mac) or import to certificate store

### Generate CSR with OpenSSL (macOS/Linux)

```bash
# Generate private key
openssl genrsa -out pass-key.key 2048

# Generate certificate signing request
openssl req -new -key pass-key.key -out pass.csr \
  -subj "/CN=Hidden Disabilities Sunflower Card Pass/O=Your Organization"

# Upload pass.csr to Apple Developer, download certificate.cer
```

## Step 3: Prepare Certificates

```bash
# Download from Apple Developer:
# - certificate.cer (Pass Type ID Certificate)
# - AppleWWDRCA.cer (WWDR Certificate - download once, keep for all passes)

# Convert to PEM format
openssl x509 -inform DER -in certificate.cer -out certificate.pem
openssl x509 -inform DER -in AppleWWDRCA.cer -out wwdr.pem

# Create PKCS12 keystore (for easier management)
openssl pkcs12 -export -in certificate.pem -inkey pass-key.key \
  -out certificate.p12 -name "Pass Certificate" \
  -CAfile wwdr.pem -caname "Apple WWDR CA"
```

## Step 4: Sign the Manifest

### Option A: Using OpenSSL (Recommended)

```bash
# Assuming you have:
# - certificate.pem (certificate)
# - pass-key.key (private key)
# - manifest.json (generated by generate_manifest.py)
# - signature (output file)

openssl smime -sign \
  -in manifest.json \
  -out signature \
  -signer certificate.pem \
  -inkey pass-key.key \
  -certfile wwdr.pem \
  -binary \
  -inform PEM \
  -outform DER
```

### Option B: Using Python

```python
import subprocess
import os

def sign_manifest(manifest_path, cert_pem, key_path, wwdr_pem, output_path):
    """Sign manifest.json with Apple certificate."""
    cmd = [
        'openssl', 'smime',
        '-sign',
        '-in', manifest_path,
        '-out', output_path,
        '-signer', cert_pem,
        '-inkey', key_path,
        '-certfile', wwdr_pem,
        '-binary',
        '-inform', 'PEM',
        '-outform', 'DER'
    ]
    subprocess.run(cmd, check=True)
    print(f"✓ Manifest signed: {output_path}")

# Usage
sign_manifest(
    'manifest.json',
    'certificate.pem',
    'pass-key.key',
    'wwdr.pem',
    'signature'
)
```

## Step 5: Update PKPass with Signature

1. Extract unsigned .pkpass (it's a ZIP file):
   ```bash
   unzip -q "Hidden Disabilities Sunflower Card.pkpass" -d pass_unsigned
   ```

2. Copy the signature file:
   ```bash
   cp signature pass_unsigned/
   ```

3. Create signed .pkpass:
   ```bash
   cd pass_unsigned
   zip -q -r "../Hidden Disabilities Sunflower Card Signed.pkpass" .
   cd ..
   ```

4. Verify structure:
   ```bash
   unzip -l "Hidden Disabilities Sunflower Card Signed.pkpass"
   ```

   Should contain:
   ```
   pass.json
   manifest.json
   signature
   logo.png
   logo@2x.png
   icon.png
   icon@2x.png
   strip.png
   strip@2x.png
   ```

## Step 6: Test on iOS Device

1. Transfer .pkpass file to iOS device (email, shared folder, etc.)
2. Open file on iOS
3. Tap "Add" button
4. Confirm add to Wallet
5. Pass should appear in Wallet app

## Complete Signing Script

Here's a complete bash script for signing:

```bash
#!/bin/bash
# sign_pass.sh - Complete pass signing workflow

set -e

CERT_PEM="certificate.pem"
KEY_PATH="pass-key.key"
WWDR_PEM="wwdr.pem"
MANIFEST="manifest.json"
UNSIGNED_PASS="Hidden Disabilities Sunflower Card.pkpass"
SIGNED_PASS="Hidden Disabilities Sunflower Card Signed.pkpass"
TEMP_DIR="pass_to_sign"

echo "Signing PKPass..."
echo ""

# Verify certificates exist
for file in "$CERT_PEM" "$KEY_PATH" "$WWDR_PEM"; do
    if [ ! -f "$file" ]; then
        echo "✗ Error: Certificate file not found: $file"
        exit 1
    fi
done

echo "✓ Certificates found"
echo ""

# Extract unsigned pass
echo "Extracting unsigned pass..."
rm -rf "$TEMP_DIR"
mkdir -p "$TEMP_DIR"
unzip -q "$UNSIGNED_PASS" -d "$TEMP_DIR"
echo "✓ Extracted: $UNSIGNED_PASS"

# Sign manifest
echo "Signing manifest..."
openssl smime -sign \
  -in "$TEMP_DIR/$MANIFEST" \
  -out "$TEMP_DIR/signature" \
  -signer "$CERT_PEM" \
  -inkey "$KEY_PATH" \
  -certfile "$WWDR_PEM" \
  -binary \
  -inform PEM \
  -outform DER
echo "✓ Manifest signed"

# Create signed pass
echo "Creating signed PKPass..."
cd "$TEMP_DIR"
zip -q -r "../$SIGNED_PASS" .
cd ..
echo "✓ Created: $SIGNED_PASS"

# Cleanup
rm -rf "$TEMP_DIR"

echo ""
echo "✓ Signing complete!"
echo ""
echo "Next steps:"
echo "1. Transfer $SIGNED_PASS to iOS device"
echo "2. Open file on iOS to add to Wallet"
echo "3. Confirm to add pass"
```

Save as `sign_pass.sh` and run:
```bash
bash sign_pass.sh
```

## Troubleshooting

### "No certificate matched"
- Verify certificate.pem contains your Pass Type ID Certificate
- Check certificate subject matches your Pass Type ID

### "Key mismatch"
- Ensure pass-key.key matches the private key used to generate the CSR
- Regenerate certificate if unsure

### Pass fails to install on iOS
- Verify signature file is binary (DER format), not text
- Check manifest.json hashes are correct
- Ensure all required files are present
- Verify Pass Type ID in pass.json matches certificate

### iOS shows "Not supported"
- Verify certificate is valid and not expired
- Check passTypeIdentifier format is correct
- Ensure teamIdentifier matches Apple Developer account

## Security Notes

- **Keep private keys secure** - Never commit to public repository
- **Rotate certificates periodically** - Update when approaching expiration
- **Use environment variables** for sensitive paths if automating
- **Consider using a pass provider service** if managing many passes
